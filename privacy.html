Privacy policy

Last updated: 26 November 2026

Who uses the app

marveen is a personal, self-hosted assistant used only by its owner on their own Google account. It is not available to other users.

Data accessed

With the owner's consent, marveen reads Gmail messages and their metadata through the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly.

How the data is used

Email content is used only to search, read and summarize the owner's own messages at the owner's request. It is not used for advertising, it is not sold, and it is not shared with third parties.

Storage

The OAuth token is stored on the owner's own server with access restricted to the system administrator. Email content is processed on demand and is not copied into a separate database.

Limited Use

marveen's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
